# 설정 파일과 템플릿

내보내기는 `format: glance-dashboard`, `version: 1`, `board`를 가진 JSON이다. 기존 v1을 유지한다. 위젯과 소스의 `configVersion` 생략은 1로 해석하며 미래 버전은 거부한다. 다른 보드의 파일은 현재 보드 ID와 revision으로 다시 검증한다. 위젯/소스 ID는 참조 무결성을 유지해 가져온다. 이미 다른 보드가 같은 source ID에 다른 설정을 사용하면 저장을 거부하므로 해당 소스를 새로 만드는 편집을 거쳐야 한다.

1MiB를 넘는 파일과 알 수 없는 형식/버전은 화면에 적용하지 않는다. JSON 문법 통과만으로 신뢰하지 않고 서버 `/validate`에서 전체 설정, URL, ID/중복/소스 참조와 한도를 검사한다. 검증은 DB에 쓰거나 upstream을 호출하지 않는다. 확인한 설정은 편집 초안에만 반영되며 undo/취소할 수 있다. 대시보드 저장이 CAS revision을 확인하고 보드 전체를 한 트랜잭션으로 확정한다. 템플릿도 같은 미리보기와 저장 경계를 따른다.

내보내기 기본 버튼은 마지막 **저장본**만 내려받고, 미저장 편집이 빠진다는 안내를 표시한다. 충돌 화면의 **내 편집 백업**은 초안을 별도 파일로 내려받는다. 파일에는 보드의 메모·북마크·공개 소스 설정이 포함되므로 개인 데이터로 보관한다. 연결 토큰/개인 일정 주소/개인 JSON 주소는 별도 암호화 저장소에만 있고 보드 파일에 포함되지 않는다. DB와 암호화 key의 운영 백업을 설정 파일로 대체할 수 없다.
